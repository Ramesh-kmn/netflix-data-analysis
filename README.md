# 🎬 Netflix Data Analysis

## 📌 Project Overview

This project analyzes Netflix movies and TV shows dataset to identify trends in content, genres, and distribution across countries. The goal is to understand patterns in Netflix's content library using data analysis techniques.

## 📂 Dataset

* Dataset: netflix_titles.csv
* Contains information about movies and TV shows including genre, country, release year, and type

## ⚙️ Approach

* Loaded dataset using Pandas
* Cleaned missing and inconsistent data
* Processed categorical variables for analysis

## 📊 Exploratory Data Analysis

* Analyzed distribution of content types (Movies vs TV Shows)
* Identified most common genres
* Studied country-wise content distribution
* Examined content trends over time

## 🔍 Key Insights

* Most content belongs to Drama and Comedy genres
* United States and India have the highest number of titles
* Netflix has added more movies than TV shows in recent years
* Content production has increased significantly over time

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
